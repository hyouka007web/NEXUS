# NEXUS Browser

Chromium-based browser with advanced scraping capabilities.

## Features

- ✅ **flutter_inappwebview** for Chrome-based browsing
- ✅ **shouldInterceptRequest** for adblocking + video harvesting
- ✅ **Adblocker** with EasyList-style filter rules
- ✅ ARD Mediathek scraper (Scrapling-style)
- ✅ Network sniffer (XHR/fetch intercepting)
- ✅ Video URL extractor
- ✅ Download manager

## Build

```bash
flutter pub get
flutter build apk --debug
```

## Requirements

- Flutter >= 3.22.0
- Dart >= 3.4.0
